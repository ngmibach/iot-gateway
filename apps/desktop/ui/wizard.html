IoT Gateway Monitor — Setup Wizard

Local monitoring · NIC · SSH · firewall · Monitoring Actions → Monitoring → Admin →

1. Local monitoring

This PC does not need Docker. The app downloads Loki and Prometheus once and runs them as local processes. You stay in this window — no external installers.


    


    

      
2. MONITORING_IP / NIC

      
Select the LAN IPv4 Promtail should push to. On WSL2 NAT, pick a Windows host address — never the WSL 172.x eth0 IP.

      

        
        
        
      

      

        
        
      

      

        
        
      

      
      

    


    

      
3. SSH host-key pin + ed25519 key

      
Pin the gateway host key, then install an app-generated ed25519 pubkey (one-time password). Password is stored via OS keyring ref.

      

        
        
      

      

        
        
      

      

        
        
      

      

        
        
      

      

        
        
      

      

        
        
        
      

      

      

    


    

      
4. Windows firewall / portproxy (guided checklist)

      
K18: Display only — the app will not auto-apply these. Loki :3100 only. Do not portproxy :9137 / :8501.

      

      

      

        
        
      

      

    


    

      
5. Launch + provision gateway

      
Starts the local control API on 127.0.0.1:9137. Provision installs the monolithic gateway agent over SSH (native Mosquitto + agent — no Docker on the device).

      

        
        
      

      
The sudo password is sent over the existing SSH session and used only as sudo -S stdin for package install. It is not saved on this PC.
