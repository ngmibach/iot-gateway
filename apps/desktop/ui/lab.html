Storage overflow warning

fake_sensor must run only for a short period. Prolonged use can overflow gateway/monitoring storage (logs, Loki, Mosquitto). The Lab auto-stops after the duration you set (max 60 minutes). Keep this wizard/app open until auto-stop — exiting cancels the in-process timer while containers may keep running.

Start / stop

Templates HOST=<gateway IP> into a staged copy of fake_sensor/, then runs a short-lived local compose project (iotgw-lab-fake-sensor). Images are always rebuilt so the templated HOST is baked into the sensor scripts.
